Both files were verified to exist before running the scorer. Predictions were **not** modified.

---

## 2. score.py Behavior

`score.py` performs **format validation only** and **chart generation**. It does **not** load ground-truth labels and does **not** compute MAE, RMSE, or any prediction-accuracy metric.

### Validation predictions (`--predictions`)

Checks performed:

1. File readable
2. Exactly 2 columns in order: `load_id`, `predicted_rate`
3. Exactly 12,000 rows
4. No missing or duplicate `load_id`
5. Load IDs match expected set `TE-000001` … `TE-012000`
6. `predicted_rate` numeric, finite, and strictly positive

### December predictions (`--december-predictions`)

Checks performed:

1. Exactly 7 columns in order: `pickup`, `delivery`, `distance`, `equipment`, `weight`, `date`, `predicted_rate`
2. Exactly 31 rows, one per day 2025-12-01 → 2025-12-31
3. Fixed scenario: Lexington → Fort Wayne, 360 miles, Dry Van, 32,000 lb
4. `predicted_rate` numeric, finite, and strictly positive

### Chart generation

After validation, `score.py` plots December `predicted_rate` vs date and saves:

`scorer_results/candidate_december.png`

Console message on success:

```
Final validation metrics are calculated by Spotter after submission.
```

**score.py does not provide a ground-truth prediction accuracy score.**

## 6. Interpretation

### Local development validation (labeled data only)

These metrics come from chronological splits on `train-test.csv` (Jan–Oct 2025). They are **not** Nov–Dec holdout scores.

| Split | MAE |
|---|---:|
| Primary (Jan–Aug → Sep–Oct) | 106.83 |
| Sensitivity (Jan–Sep → Oct) | 113.29 |

### Final Nov–Dec holdout

- `validation.csv` has **no labels** locally.
- `score.py` validates submission format and generates the December chart only.
- **No local MAE exists** for the 12,000 final predictions.
- Official accuracy, if any, is determined by Spotter **after external submission**.

Do not invent an official Spotter score.

---

## 7. Known Limitations

1. **No local holdout accuracy** — `score.py` cannot score prediction quality without ground truth.
2. **Flat December chart** — by design of locked feature set Q (no calendar features).
3. **Development MAE ≠ submission score** — Phase 3.5 MAE used Sep–Oct proxy; Nov–Dec distribution may differ.
4. **External evaluation only** — Spotter's final metric and ranking are outside this repository.
